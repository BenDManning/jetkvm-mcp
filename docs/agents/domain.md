# Domain docs

This is a single-context repository.

Before exploring or changing behavior:

1. Read `CONTEXT.md` for the shared vocabulary.
2. Read `docs/product-contract.md` for canonical product scope, compatibility, and support rules.
3. Read `docs/adr/README.md` and ADRs relevant to the affected area.
4. Follow their pointers to operational, security, and protocol documents when applicable.

Keep `CONTEXT.md` and `docs/agents/` concise. They index the canonical documents and must not duplicate their contracts or decisions.

Use the vocabulary in `CONTEXT.md`. Explicitly flag proposed work that conflicts with an accepted ADR.
