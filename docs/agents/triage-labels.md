# Triage labels

Map canonical triage roles only to semantically compatible labels that already exist in this repository.

| Canonical role | Existing GitHub label |
| --- | --- |
| `needs-triage` | _unconfigured_ |
| `needs-info` | `question` |
| `ready-for-agent` | _unconfigured_ |
| `ready-for-human` | _unconfigured_ |
| `wontfix` | `wontfix` |

The existing `bug` and `enhancement` labels provide the two category roles.

For an unconfigured role, stop and ask the maintainer. Do not infer a substitute or create a label.

Before changing labels, read the live repository labels. Never create, rename, or delete a GitHub label without maintainer approval.
